# Industrial Process Fault Detection and Diagnosis Using Machine Learning

1. *Project Overview*
- This project aims to develop a machine learning system capable of detecting abnormal operating conditions in industrial chemical processes and classifying different types of process faults.

- The system will analyse process variables such as temperature, pressure, flow rate, and other relevant operating measurements to distinguish normal operating conditions from abnormal ones.


2. *Project Objectives*
- Explore and understand industrial process data.
- Identify patterns associated with normal and faulty operating conditions.
- Develop machine learning classification models for fault detection.
- Evaluate and compare model performance.
- Interpret model predictions from an engineering perspective.


3. *Technologies*
- Python
- Numpy
- pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
